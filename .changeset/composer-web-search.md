Search the public web from the composer Search button, with approval once, for the session, or always. Opening a site from the results asks for that domain, or for all public URLs in that conversation until the page reloads. A redirect to a different site asks before that site is opened. Sending an image with web search enabled answers without the fetch tool; Search still refuses the image. After an approved search, keyboard focus moves to Stop.
