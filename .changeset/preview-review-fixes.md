Destructive actions ask with the granted confirmation dialog before they run. A custom bind address is saved only after you confirm it. A benchmark start waits a limited time for the previous exclusive release. An uncertain service start or stop is shown as unknown, and Stop stays available. Light warning text, secondary buttons, and disabled-button tips are readable. Long WAV decode and encode yield so the window can paint. Chat and device labels follow the shared speech, embed, and accelerator classifiers, including VL models in the vision catalog. Resuming a benchmark is blocked while that suite's history is being deleted. Stop & Unload shows stopped only when the sidecar confirms the listener stopped, and unknown when it does not; Apply can be used for a typed custom address and does nothing if that confirmation is cancelled. Deleting a variant or cached model, or applying network settings, checks again that no benchmark or endpoint self-test started while the confirmation was open.
